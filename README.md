# سایت مشاوره تخصصی ISO/IEC 17025:2017

سایت حرفه‌ای و مدرن برای راهنمایی بندبه‌بند استاندارد ISO/IEC 17025، الزامات، پیاده‌سازی، مستندات موردنیاز و چک‌لیست هم‌راستا با رویه‌های مرکز ملی تایید صلاحیت ایران (NACI).

## ساختار پروژه

```
iso17025-site/
├── index.html          # صفحه اصلی (تک‌صفحه‌ای)
├── css/
│   └── style.css       # استایل‌های کامل (RTL + ریسپانسیو)
├── js/
│   └── main.js         # منوی موبایل، آکاردئون بندها، فیلتر، فرم
├── netlify.toml        # تنظیمات دیپلوی Netlify
└── README.md
```

## ویژگی‌ها

- طراحی کاملاً RTL و فارسی با فونت Vazirmatn
- منوی همبرگری حرفه‌ای در موبایل
- دسکتاپ کاربرپسند با ناوبری ثابت
- بندبه‌بند استاندارد (۴ تا ۸) با الزامات، نحوه پیاده‌سازی و مستندات
- جدول مستندات بر اساس چک‌لیست‌های رایج ارزیابی NACI
- مسیر ۵ مرحله‌ای پیاده‌سازی
- بخش خدمات مشاوره
- فرم تماس آماده برای Netlify Forms

## نحوه انتشار

### GitHub Pages
1. محتوای پوشه را در ریپازیتوری خود (مثلاً `Iso17025`) قرار دهید.
2. در Settings → Pages، Source را روی branch اصلی و root تنظیم کنید.
3. سایت در آدرس `https://USERNAME.github.io/Iso17025/` در دسترس خواهد بود.

### Netlify (پیشنهادی برای فرم و backend)
1. پروژه را به Netlify متصل کنید یا فایل‌ها را Drag & Drop کنید.
2. برای فعال‌سازی فرم:
   - به تگ `<form>` اضافه کنید: `netlify` یا `data-netlify="true"`
   - یک فیلد مخفی اضافه کنید:
     ```html
     <input type="hidden" name="form-name" value="contact" />
     ```
3. در صورت نیاز به API یا توابع سرور، از Netlify Functions استفاده کنید.
