# فرم‌های استاندارد ISO/IEC 17025:2017

این پوشه شامل ۱۰ فرم حرفه‌ای قابل چاپ بر اساس الزامات استاندارد است:

| کد | عنوان | کاربرد اصلی |
|----|--------|-------------|
| F-01 | خط‌مشی و بیانیه بی‌طرفی | بند ۴.۱ |
| F-02 | تعهدنامه بی‌طرفی کارکنان | بند ۴.۱ |
| F-03 | تعهدنامه محرمانگی (رازداری) | بند ۴.۲ |
| F-04 | شناسایی و ارزیابی ریسک بی‌طرفی | بند ۴.۱ |
| F-05 | بررسی درخواست / قرارداد | بند ۷.۱ |
| F-06 | دریافت قلم آزمون / کالیبراسیون | بند ۷.۴ |
| F-07 | کار نامنطبق | بند ۷.۱۰ |
| F-08 | ثبت و رسیدگی به شکایت | بند ۷.۹ |
| F-09 | اقدام اصلاحی | بند ۸.۷ |
| F-10 | ارزیابی صلاحیت پرسنل | بند ۶.۲ |

دانلود یکجا: [ISO17025-Forms-Pack.zip](ISO17025-Forms-Pack.zip)

فرم‌ها با فونت Cairo و طراحی RTL تهیه شده‌اند و قابل چاپ و پر کردن دستی هستند.
